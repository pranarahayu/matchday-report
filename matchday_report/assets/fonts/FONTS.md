# Fonts

* **Poppins** (Light/Regular/Medium/Bold) – titles, scores, numbers. Included.
* **Be Vietnam Pro** – body text. Not included: download it from Google Fonts and drop
  `BeVietnamPro-Light.ttf`, `BeVietnamPro-Regular.ttf`, `BeVietnamPro-Medium.ttf`,
  `BeVietnamPro-Bold.ttf` into this folder. Until then Poppins is used for body text too.

Both are licensed under the SIL Open Font License 1.1 (https://openfontlicense.org),
which allows bundling them with this app.
