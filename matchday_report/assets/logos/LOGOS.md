# Logo files

PNG, square-ish, transparent background, ~512 px. Missing files show a placeholder badge.
The app's *Data & glossary* tab lists every file it looks for, for the selected competition.

## Competitions (`assets/logos/competitions/`)

- `bri-super-league.png` – BRI Super League
- `pegadaian-championship.png` – Pegadaian Championship
- `indonesian-women-s-league.png` – Indonesian Women's League
