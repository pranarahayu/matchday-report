# Logo files

PNG with a transparent background, any size (they are scaled). The app matches
files to club names loosely: case, punctuation and the words FC/PS are ignored, and one
name may contain the other (`persib.png` is used for "PERSIB Bandung").

The app's *Data & glossary* tab shows, for the selected competition, which clubs still
use a placeholder badge.

## Competitions (`assets/logos/competitions/`)

- `pegadaian-championship.png` – Pegadaian Championship
